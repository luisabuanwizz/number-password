# 2 Practice Programs

## Description
This project has two small programs that read user input and respond accordingly:
* **Even or Odd checker:** Determines if the user entered number is even or odd.
* **Password Gatekeeper:** Checks the user inputted password to see if its strong enough or not based on the password being 8+ letters long or not.

## How to Run the Program
1. Copy the code from `main.py`.
2. Go to a website that can run python like OnlineGDB.
3. Paste the code into the main text editor window.
4. Find a button with "Start" to execute the script.

## Input Needed
The program will ask you for the following inputs in the terminal window:
1. **A whole number:** An integer value (e.g., `12` or `7`) to check for even or odd status.
2. **A password:** Any text string (e.g., `secretpass167`) for proper length checking of the password.

## Sample Output
```text
Enter a whole number: 7
Your number is odd.

Input your password: secret
Password is too short.
```
